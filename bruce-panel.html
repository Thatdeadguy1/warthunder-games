BRUCE
Command panel for Bruce firmware on the ESP32-S3. Connect over USB (Web Serial) to drive Bruce's real CLI, or launch Demo Mode to explore the interface without hardware.
🔌 CONNECT VIA USB (WEB SERIAL)
Plug the ESP32-S3 into this computer over USB. Web Serial hands the browser a direct pipe into Bruce's serial CLI — the same one you'd get from screen /dev/ttyUSB0 115200. Bruce initializes serial at 115200 by default.
BAUD ⚠ Web Serial not available in this browser
OR TRY WITHOUT A DEVICE
🎮 DEMO MODE
Full UI with simulated Bruce responses — no hardware required. Great for exploring the command surface.
ℹ️
Only commands that Bruce actually exposes in its serial CLI are wired to buttons here. Menu-driven features (BLE spam, Evil Portal, RFID/NFC, TV-B-Gone, deauth) are not part of the CLI — drive them via the nav command in the System tab, or on-device.
